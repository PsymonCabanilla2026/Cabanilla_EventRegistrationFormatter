# Student Event Registration Formatter

## Project Description
This project is a Python program that collects student information and event details. It cleans and formats text inputs and displays the event date in a readable format.

## Features
- Accepts student first and last names.
- Accepts the student's section.
- Accepts the event name.
- Accepts the event year, month, and day.
- Formats names using title case.
- Converts the section and name code to uppercase.
- Formats the event date using datetime.

## Programming Language
Python

## String Methods Used**
- strip()
- title()
- upper()

## Date/Time Feature Used
- datetime
- strftime()

## Program Versions
1. Version 1 - Basic input and output.
2. Version 2 - Added string formatting.
3. Version 3 - Added date formatting.

## How to Run
1. Open the project in Visual Studio Code.
2. Open Version3.py.
3. Run the Python file.
4. Enter the required student and event information.
